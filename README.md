# 📊 E-commerce Analytics 

> **Projeto de Data Analytics focado na análise de performance de vendas em e-commerce e marketplaces.**

O **E-commerce Analytics** é um projeto desenvolvido com o objetivo de transformar dados de vendas em **informações relevantes para tomada de decisão**, explorando indicadores de performance, comportamento de vendas e oportunidades de negócio.

A proposta é construir um projeto **end-to-end**, passando pelo tratamento dos dados até a análise e visualização das informações em um dashboard interativo no **Power BI**.

---

## 🎯 Objetivo

O projeto busca responder perguntas de negócio como:

* 📦 Quais produtos apresentam melhor desempenho?
* 💰 Como está a evolução do faturamento?
* 🛒 Como os pedidos estão distribuídos?
* 📈 Quais períodos apresentam maior volume de vendas?
* 🏷️ Quais categorias possuem maior participação nas vendas?
* 🌎 Quais regiões apresentam maior desempenho?
* 📊 Quais indicadores merecem maior atenção?

A ideia não é apenas visualizar números, mas **transformar dados em insights que possam apoiar decisões de negócio**.

# 📊 Dashboard

O dashboard foi desenvolvido no **Power BI**, com foco em uma apresentação visual simples, objetiva e orientada à análise.

## 📌 Página 1 — Visão Geral

A primeira página apresenta uma visão consolidada da operação, permitindo acompanhar os principais indicadores de vendas e entender rapidamente o desempenho do negócio.

Entre os elementos trabalhados estão:

* Indicadores principais de vendas;
* Evolução temporal;
* Distribuição das vendas;
* Comparativos de performance;
* Gráficos para identificação de tendências;
* Filtros interativos.

A proposta dessa página é funcionar como um **painel executivo**, permitindo obter uma visão geral antes de aprofundar a análise.

---

## 📌 Página 2 — Análise de Vendas

A segunda página aprofunda a análise dos dados, permitindo explorar o desempenho das vendas por diferentes dimensões.

Entre as análises trabalhadas estão:

* Performance por categoria;
* Distribuição das vendas;
* Comparação entre períodos;
* Indicadores de desempenho;
* Análise detalhada dos dados;
* Segmentações para exploração dos resultados.

O objetivo é permitir que o usuário saia de uma visão geral e consiga **investigar os dados de forma mais detalhada**.

---

# 📈 Principais indicadores

O projeto trabalha com métricas que ajudam a acompanhar a performance da operação, como:

**Faturamento**
Valor total gerado pelas vendas.

**Quantidade de pedidos**
Volume de pedidos realizados.

**Ticket médio**
Valor médio gerado por pedido.

**Receita**
Indicador utilizado para acompanhar o desempenho financeiro das vendas.

**Performance por categoria**
Comparação do desempenho entre diferentes categorias de produtos.

> Novos indicadores e análises serão adicionados conforme a evolução do projeto.

---

# 🔎 Análise orientada a negócio

Um dos principais objetivos do projeto é evitar uma abordagem baseada apenas em gráficos.

A análise busca responder:

> **“O que esses dados significam para o negócio?”**

Por isso, o dashboard foi pensado para facilitar a identificação de:

* tendências;
* oportunidades;
* produtos de destaque;
* períodos de maior desempenho;
* categorias relevantes;
* possíveis pontos de atenção.
